# PRO1001 Work Requirement 4 - Product Ratings Dashboard
## Exercise requirements
This task will build a small web page that fetches product data from a remote API (Fake Store API ) and visualizes the product ratings using Highcharts. Show the same dataset using at least two different chart types and make sure the page is accessible.

### Objectives
* Fetch and transform data from an external API.
* Display data using at least two different Highcharts chart types.
* Apply basic accessibility for both the page and the charts.
